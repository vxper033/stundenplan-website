🎨 Fächer-Legende · Woche A

Alle Fächer der angezeigten Woche mit Stundenanzahl

🔒 Hinweis: Passwortschutz ist reiner Frontend-Schutz (Demo) · Pläne & Zeiten werden lokal im Browser gespeichert · Jede Person hat eigene Zeiten

📖 Anleitung: 10 Stunden + eigene Zeiten

Alles ist bewusst nur mit HTML, CSS & JS gebaut. So passt du alles an:

1️⃣ Personen & Passwörter: Im Bereich USERS kannst du vorname, klasse und passwort ändern. Beispiel: passwort: "meinGeheim123"
2️⃣ Eigene Zeiten pro Person (10 Stunden): Jede Person hat ein eigenes Feld zeiten mit 10 Einträgen. Die Personen sind bewusst unterschiedlich eingestellt. Beispiel:
{ stunde:1, von:"07:45", bis:"08:30" } – einfach Uhrzeit ändern. Im Browser geht das auch über den Button ⏰ Zeiten.
// Beispiel Lena (früh):
zeiten: [
 { stunde:1, von:"07:45", bis:"08:30" },
 { stunde:9, von:"15:30", bis:"16:15" },
 { stunde:10, von:"16:20", bis:"17:05" },
]
// Beispiel Finn (spät):
zeiten: [
 { stunde:1, von:"08:00", bis:"08:45" },
 { stunde:9, von:"16:00", bis:"16:45" },
 { stunde:10, von:"16:50", bis:"17:35" },
]
3️⃣ Stundenplan mit 10 Zeilen: Unter plaene: { A: [...] } ist jede Zeile eine Stunde (jetzt 10 Zeilen), jede Zeile hat 5 Spalten = [Mo, Di, Mi, Do, Fr]. null = Frei.
// 9. Stunde: Mo, Di, Mi, Do, Fr
[ null,
  { fach:"Förder", lehrer:"Bauer", raum:"204" },
  null, null,
  { fach:"Informatik AG", lehrer:"Lehmann", raum:"I2" } ],
4️⃣ Wochen-Rhythmus: KW 1 = Woche A, KW 2 = B … danach wieder A. Falls eure Schule anders startet, ändere ROTATION_OFFSET (0–3).
5️⃣ Farben: In SUBJECT_COLORS stehen die Fach-Farben. Einfach Hex-Code tauschen.
